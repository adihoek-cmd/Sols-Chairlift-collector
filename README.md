# 🎿 Chairlift Collector

A browser & mobile game where you ride a chairlift up the mountain and collect (or avoid!) items that previous skiers dropped on the slope below.

**[▶ Play it live](https://YOUR_USERNAME.github.io/chairlift-collector/)**

## 🕹️ How to Play

- **90 seconds** to ride up the mountain
- **Tap/click items** as they scroll past you downward
- Collect as many as you can before they disappear below the chairlift
- **AVOID rocks and bushes** — they break your combo and cost 5 points!
- Enter your **3-letter IGN** at the end and compete on the leaderboard

## 🏆 Items & Points

| Item | Points |
|------|--------|
| 🧤 Glove | +1 |

| 😱 Fallen Skier | +100 |
| 🪨 Rock (trap) | −5 & combo reset |
| 🌿 Bush (trap) | −5 & combo reset |

## ✨ Features

- Fully procedural Web Audio après-ski music — no files needed
- Sound effects for every action
- Persistent leaderboard via localStorage (top 10 scores, 3-letter IGN)
- Combo system with multiplier display
- Speed ramps up as you ascend
- Trees, ruts, and mountains scroll downward as you climb
- Desktop (click) and mobile (tap) friendly
- Zero dependencies — single HTML file

## 🚀 Deploy to GitHub Pages

1. Add `index.html` (rename `chairlift-collector.html`) to your repo root
2. **Settings → Pages → Source: main branch / root**
3. Live at `https://USERNAME.github.io/REPO/`

## Local Play

Open `index.html` in any modern browser — that's it.
